# Friction-Forensics

---

## About

This repository supports the PhD thesis *"Friction-Forensics: A Friction Coefficient Assessment Framework for Accident Reconstruction."* The research addresses a five-decade gap: since the 1970s, no validated method exists to translate standardized friction indices into the friction coefficient that governed a vehicle's braking at the time of an accident.

The project integrates:
- **FAIR data integration** of existing friction data from international projects and regulatory databases
- A **paired database** of 5,000+ laboratory-field measurements including new and worn-tyre data
- A **novel tribometer** for full friction-slip curve characterization under field conditions
- A **Bayesian assessment framework** for legally defensible uncertainty quantification
